Unofficial • Android • Rust + Kotlin

Rust Telegram Mobile

An experimental Android Telegram client with a Rust-first core, real MTProto integration, JNI-backed state and a Jetpack Compose UI.

View on GitHub Roadmap

Stable public APK releases are not available yet. Development builds should not be treated as production-ready.

What is already here

Rust-first core
State, reducers, persistence, commands and events live in Rust.
Real Telegram backend
MTProto integration with reconnect and update synchronization foundations.
Messaging foundation
History pagination, search, reliable sending, edits and deletes.
Android shell
Kotlin, Jetpack Compose and an ARM64 JNI bridge.

Architecture

Telegram → crates/telegram → crates/core → crates/android-bridge → Android Compose

Status

The project is under active development. Reactions, pinned messages, contacts/profiles, richer media UX and other daily-driver features are still being completed.
